# Портфолио · MaxDiWay

Одностраничный сайт-портфолио. Статические файлы, ноль зависимостей, ноль сборки.

```
index.html    разметка и секции
styles.css    дизайн-система (жидкое стекло, токены, тени)
content.js    ← ТЕКСТЫ И ССЫЛКИ, редактировать здесь
app.js        рендер карточек, переключение языка, анимации
.nojekyll     чтобы Pages не трогал файлы
```

## Как поменять текст или ссылку

Всё в `content.js`:

* **`LINKS`** — в самом верху. Вставь адрес → кнопка появится сама.
  Пустая строка `''` → кнопка скрыта.
  Сейчас пустые: `discord`, `telegram`, `resume`, `aura.apk`.
* **`I18N.ru` / `I18N.en`** — все надписи на сайте. Оба языка обязательны:
  при отсутствии ключа в `en` подставится русский.
* **`PROJECTS`** — три карточки проектов: метрики, теги, фичи и разбор
  «где было сложно». Поддерживается `<code>` и `<em>` внутри текста.

Язык также ставится через `?lang=en` в адресе, дальше выбор запоминается
в `localStorage`.

## Локальный просмотр

Файл открывается и напрямую (`index.html`), но чтобы проверить всё как в
браузере — лучше через сервер:

```bash
cd portfolio
python -m http.server 5173
# → http://localhost:5173
```

## Деплой на GitHub Pages

```bash
cd portfolio
git init
git add .
git commit -m "портфолио: первая версия"
git branch -M main
git remote add origin https://github.com/maksim8560/portfolio.git
git push -u origin main
```

Дальше в репозитории: **Settings → Pages → Source: GitHub Actions**.
Workflow уже лежит в `.github/workflows/deploy-pages.yml`, он просто
заливает папку как есть — собирать нечего.

Адрес будет `https://maksim8560.github.io/portfolio/`.

## Заметки

* Тёмная тема по умолчанию; светлая подхватывается из системных настроек,
  переключается переменной в localStorage (`portfolio.theme`).
* Уважается `prefers-reduced-motion` — анимации и «дышащий» фон
  выключаются автоматически.
* Разметка не использует `content-visibility` намеренно: он ломает
  `IntersectionObserver` для потомков, и анимации появления перестают
  срабатывать.
